GitHub Pages 公開手順
1. GitHubにログインし、新規のPublicリポジトリを作成（例：ippan-joshiki-quiz）。
2. リポジトリの Add file → Upload files から index.html, past.html, prediction.html の3ファイルをアップロードし、Commit changes。
3. Settings → Pages → Build and deployment で Source: Deploy from a branch、Branch: main / (root) を選択して Save。
4. Pages画面に表示されたURLにiPhoneのSafariでアクセス。
5. Safariの共有ボタン → ホーム画面に追加、でアプリのように起動できます。

注意：Publicリポジトリに公開した場合、URLを知っている人以外にも内容が閲覧可能です。問題集を非公開にしたい場合は認証付きのHostingを利用してください。
